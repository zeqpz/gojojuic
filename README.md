# Juice Dojo

An original fruit-slicing slot for [Stake Engine](https://stake-engine.com), built on the workflow and HUD of
[zeqpz/orleans](https://github.com/zeqpz/orleans) and the skills/agents in [zeqpz/workflow](https://github.com/zeqpz/workflow).

## How it plays

- **Base spin = one wave.** A 4x4 formation of fruit falls through the dojo as real bodies (gravity + quadratic air
  drag, so each settles at its own terminal speed; collisions with mass and spin). As it passes through the board the
  blade slices every paying line, halves and juice fly, and the rest falls on out the bottom, bumping into whatever is
  in the way. 10 lines (4 rows, 4 columns, 2 diagonals) pay **both ways**: 3 or 4 of a kind from either end. 3+ lines in
  one wave is a combo (x2, 5+ lines x3). **No bombs in the base game.**
- **Fruit Frenzy** (3+ golden star fruit): up to **50 waves**, faster as it goes, richer in high fruit. Any wave may
  carry a **bomb** in place of one fruit: 3.5% on the first wave, +0.4% each wave, capped at 20%. A bomb ends the
  frenzy (wins are kept) after a slow-motion camera close-up. Multiplier peaches (x2/x3/x5/x10) are **per wave**:
  the peaches in a wave add up and multiply that wave's line wins only; with no line they do nothing, and nothing
  carries over. Frost grapes knock the bomb chance back to its start; side fruit pays every wave; clearing all 50
  brings the Gold Melon finale.
- **Bonus Buy** (orleans' 3-card shop): **Fruit Frenzy 77x**, **Xtreme Frenzy 265x** (peaches in almost every wave, often two,
  always x3/x5/x10; bomb 1.8% +0.15%/wave), **Bonus Boost 1.25x per spin** (toggle; Frenzy 1.6x as likely).
- RTP 96.70% in all four modes, max win 5,000x. Base hit rate 31.9%, frenzy ~1 in 193 spins (1 in ~120 boosted).

## Layout

| Path | What |
|---|---|
| `math/juice_math.py` | The whole math model: simulates books and writes `math/publish_files` (books, LUTs, index.json). `stats` for a quick estimate, `sim` to publish. LUT weights pin RTP to exactly 0.967. |
| `frontend/index.html`, `game.js` | The game: canvas physics, blade, juice, frenzy, finale, bet replay, resume. |
| `frontend/bonus.css` | **The orleans bonus UI, identical**: the Bonus Buy shop, the bonus intro and the in-bonus counter plate, extracted the same way; Juice Dojo overrides at the end. |
| `frontend/hud.css`, `hud.js` | **The orleans HUD, identical**: every orleans rule that styles `.bottom` and its pop-ups, extracted from the live orleans page in cascade order, plus its `buildHud`, `placePop`, `spinArrows` and its page-fit scaling (`--fit`, `--hs`). Restyle in overrides, don't hand-edit the extracted block. |
| `frontend/rgs.js`, `mock_rgs.py` | RGS client and local mock RGS (from orleans; port 8766). |
| `tools/blender/fruitkit.py` (+ `fruits_more.py`) | Procedural 3D fruit in Blender 5.2 (Cycles), in an old-casino / fish-table style: lacquer clear coat, hard highlights, coloured rim lights, polished gold specials; halves are real bisected geometry with a glossy INSIDE material on the cut. Renders a 64-frame tumble, a 24-frame rocking half and the 8-frame slice-open clips. |
| `tools/pack_sprites.py` | Packs the Blender frames into one WebP sheet per fruit (`frontend/assets/fruit/`) + `meta.json`, and `art/blender/contact.png`. |
| `tools/sfx/jd.py`, `jd_spec.py`, `accents.py` | Sound effects: OpenRouter Seed Audio takes (prompts in `jd_spec.py`) cut, cleaned and mastered with fallslotsga's sfx tools -> `frontend/assets/sfx/*.ogg` + `sfx.json` (24 sets, 67 takes: a slice per fruit, swoosh, drop, bump, fuse, boom, frenzy_start, multiplier, frost, combo x3 rising, line_win, big_win, coin_tick). `game.js` plays a different take each time with a pitch nudge; synth fallback. Run `fallslotsga/.venv python tools/sfx/jd.py all`. |
| `tools/gen_art.py`, `tools/orimg.py` | OpenRouter image generation (background, logo, 2D references). Key: `%USERPROFILE%\.juicedojo\openrouter-key.txt`, else `Documents\gamdevkey.txt`; never printed. |
| `tools/gen_scene.py`, `pack_casino.py`, `pack_features.py` | The scene: a glossy 2000s fruit-machine casino hall (CASINO jobs: red lacquer, gold dragon pillars, sunburst, a beam of marquee bulbs) and two silk lanterns -> `frontend/assets/scene/casino*.webp`, `lantern2.webp`; `casino.json` holds the painted bulbs' positions, which `placeBulbs()` lights as chase lights (faster during wins and the frenzy). Also the features screen's plate + icons -> `assets/features/`. (The older cartoon wall / outdoor art is still generated by the same script; `pack_scene.py` packs the outdoor set.) |
| Performance | Nothing on screen animates a CSS filter or a background position (they repaint every frame): glows breathe by opacity. Fruit sheets are drawn once onto the canvas at load so the GPU has them before the first wave; touch devices load `assets/fruit/m/` (3/4 size, 144 px cells). |
| Opening (`game.js` runIntro / runFeatures) | As zeqpz/orleans: the black-and-white SMUKIEZ ident (letters + sounds from orleans, `assets/intro_letters`, `assets/sfx/intro`) while loading, then the Juice Dojo title over three ninja plates that explain the game, CLICK TO PLAY. |
| Cinematics (`game.js` cam, starCinematic) | Slow-motion camera close-ups on line wins; the star fruit (bonus icons) get a heartbeat-timed close-up, three or more a riser, a beat of silence and one hit. |
| `tools/sfx/gen_music.py`, `pack_music.py` | Lyria 3 music: calm ninja loops for the base game and the frenzy, cut to whole bars; key / BPM / beat grid in `assets/music/music.json`. `SFX.music.cue()` plays in-key koto / bell / drone stingers on that grid for stars, lines, combos, wins, big wins, the bonus and the bomb. |
| `tools/sfx/gen_sfx2.py`, `remaster.py` | Seed Audio takes for the cinematic set; `remaster.py` rebuilds every effect crisp at 48 kHz (bandwidth extension + EQ) from `art/raw/audio/sfx_orig/`. |

## Run

```
python -m venv .venv && .venv\Scripts\python -m pip install zstandard numpy scipy soundfile pillow
.venv\Scripts\python.exe frontend/mock_rgs.py
```
then http://localhost:8766/index.html?sessionID=test&rgs_url=http://localhost:8766&lang=en&device=desktop
(the first start unpacks the books into `math/mock_cache/`, ~12 s).

Rebuild art: `blender -b --factory-startup --python tools/blender/fruitkit.py -- all build,render` (~3 min), then
`python tools/pack_sprites.py`. Live: in the Blender MCP session `exec` fruitkit.py and call `gallery()`.

Rebuild math: `python math/juice_math.py sim --base 300000 --bonus 60000` (~10 min), delete `math/mock_cache/`,
restart the mock. Keep `frontend/rules.js` (pays, frenzy numbers) in step with the constants in `juice_math.py`.
